# Lu on the PC Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Lu runs on Jack's Windows PC, with Bonsai 2 27B on its graphics card
handling both his replies and his judges, and thinking switched off.

**Architecture:** There is one small code change: a `LLM_DISABLE_THINKING`
setting that adds `chat_template_kwargs: { enable_thinking: false }` to every
chat request. Everything else is deployment. Two Windows Task Scheduler tasks
run `llama-server` and Lu at boot. Both bind to localhost only. The mini's
copy of Lu is stopped and kept as the way back.

**Tech Stack:** Node 26 (`node --test`), discord.js 14, `node:sqlite`, and
PrismML's llama.cpp build `prism-b10777-e3de715` (Windows CUDA 13.3).
Windows 11 Pro, PowerShell, and Task Scheduler.

**Spec:** `docs/superpowers/specs/2026-11-13-lu-on-pc-design.md`

## Global Constraints

- The repo requires Node ≥ 26. On the PC, install `OpenJS.NodeJS` 26.x
  (winget currently offers 26.12.1). Jack approved this on 2026-11-13.
- `npm test` must pass before every commit.
- The model server listens only on `127.0.0.1:8080`. Nothing listens on the
  network.
- Lu must never run on the mini and the PC at the same time.
- Never commit `.env`. Copy it over SSH only.
- SSH alias: `mrpc`, lowercase. The remote shell is PowerShell, so use `;` to
  chain commands, never `&`.
- Model file: `C:\bonsai\bonsai.gguf`. Binaries: `C:\bonsai\bin`. Both are
  already in place.
- Server command:
  `C:\bonsai\bin\llama-server.exe -m C:\bonsai\bonsai.gguf -ngl 99 -fa on -c 16384 --cache-type-k q4_0 --cache-type-v q4_0 --jinja --parallel 2 --host 127.0.0.1 --port 8080`
- When Lu is offline because the PC is busy gaming, off or restarting, that is
  accepted: there is no fallback.
- Changelog notes are written for server members, lowercase, with no
  internals (see the existing entries).

## Review Focus

1. **`LLM_DISABLE_THINKING` set to `TRUE`, `1` or ` true`.** The repo's
   convention is exactly `"true"` (see the `MODERATION_ENABLED` comments), so
   anything else means off. Pinned in Task 1.
2. **Setting absent on the mini.** Requests must stay exactly as they are
   today, with no `chat_template_kwargs` key at all. Pinned in Task 1.
3. **Judges must not think either.** `chat()` (used by the judges) and
   `chatWithFinish()` (replies) must both carry the flag, or the 3-token
   addressee judge returns nothing. Pinned in Task 1, and checked live in
   Task 4.
4. **Lu starts before the model server is ready.** The model takes about 15
   seconds to load. Lu's start script waits for `GET /health` to return 200
   before starting Node. Checked in Task 3.
5. **Prompt bigger than an 8K slot.** `--parallel 2` splits the 16K window
   into two 8K slots. Measure the real prompt with 40 messages of history.
   Checked in Task 4.

- [ ] **Step 1: Write the failing tests**

In `test/config.test.js`, add `disableThinking: false` to the expected object
in the existing "correct shape" test, and add:

```js
test('LLM_DISABLE_THINKING is on only for exactly "true"', () => {
  const base = { LLM_CHAT_MODEL: 'c', LLM_JUDGE_MODEL: 'j', LLM_EMBED_MODEL: 'e' };
  assert.equal(loadLlmConfig({ ...base, LLM_DISABLE_THINKING: 'true' }).disableThinking, true);
  for (const v of [undefined, '', 'false', 'TRUE', '1', ' true']) {
    assert.equal(loadLlmConfig({ ...base, LLM_DISABLE_THINKING: v }).disableThinking, false, `value ${v}`);
  }
});
```

In `test/llm.test.js`, using the existing `stubFetch`:

```js
test('with disableThinking, chat and chatWithFinish ask the server not to think', async () => {
  const { fetchImpl, calls } = stubFetch({ choices: [{ message: { content: 'x' }, finish_reason: 'stop' }] });
  const llm = createLlm({ baseUrl: 'http://x/v1', fetchImpl, disableThinking: true });
  await llm.chat({ model: 'm', messages: [] });
  await llm.chatWithFinish({ model: 'm', messages: [] });
  for (const c of calls) assert.deepEqual(c.body.chat_template_kwargs, { enable_thinking: false });
});

test('without disableThinking, requests carry no chat_template_kwargs', async () => {
  const { fetchImpl, calls } = stubFetch({ choices: [{ message: { content: 'x' }, finish_reason: 'stop' }] });
  const llm = createLlm({ baseUrl: 'http://x/v1', fetchImpl });
  await llm.chat({ model: 'm', messages: [] });
  await llm.chatWithFinish({ model: 'm', messages: [] });
  for (const c of calls) assert.equal('chat_template_kwargs' in c.body, false);
});

test('embed never carries chat_template_kwargs', async () => {
  const { fetchImpl, calls } = stubFetch({ data: [{ embedding: [1] }] });
  const llm = createLlm({ baseUrl: 'http://x/v1', fetchImpl, disableThinking: true });
  await llm.embed({ model: 'e', input: ['a'] });
  assert.equal('chat_template_kwargs' in calls[0].body, false);
});
```

### Task 3: Set up the PC

  Global Constraints and appends its output to

  `http://127.0.0.1:8080/health` every 2 seconds for up to 120 seconds, then
